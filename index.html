📖 Quick Guide: How to Export Your Chat

📱 iPhone (iOS)

Open chat → Tap contact name → Scroll down → Tap Export Chat → Select Without Media → Save to Files.

🤖 Android

Open chat → Tap 3 dots (top right) → Tap More → Tap Export chat → Select Without Media → Save/Share file.

💻 Desktop (PC / Mac)

Open WhatsApp Desktop / Web → Open chat → Click contact name at top → Scroll down → Click Export chat → Save `.txt` file.
