# unlinked: Limerence 🥀

> **Turn romantic obsession into objective reality.**  
> A mobile-first, zero-cost, 100% private relationship audit tool for WhatsApp chat logs.

---

## 📌 Overview

**unlinked: Limerence** is a client-side data analysis tool designed to help daters cut through emotional fog, overthinking, and mixed signals. By analyzing standard WhatsApp chat export files, the app computes hard, objective metrics regarding communication balance, daily initiation ratios, reply latencies, and low-effort behavior.

It serves as an empathetic, data-driven precursor and lead magnet for **unlinked**, a 90-day structured emotional recovery platform.

---

## ✨ Key Features

* **100% Client-Side Privacy:** All file processing happens locally in the user's browser. Chat files are never uploaded, stored, or transmitted to any server.
* **Daily Initiation Engine:** Calculates exact ratios for who starts conversations day-to-day.
* **Low-Effort Morning Opener Detection:** Scans for short "good morning" texts that lack follow-through or lead to immediate thread drop-offs.
* **Reply Delay Analytics:** Measures response time gaps for both parties.
* **Turning Point Detection:** Splits chat logs (e.g., First 60 Days vs. Recent Dynamics) to pinpoint where effort dropped off.
* **Topic Carrying Score:** Measures word count balance, paragraph lengths, double-texts, and questions asked.

---

## 🔒 Privacy & Security First

Security and user privacy are fundamental to this project:
- **Zero Database / Zero Server:** No backend database exists.
- **Local Parsing:** JavaScript parses text timestamps directly in the client's RAM and discards data upon page refresh.
- **GDPR / POPIA Compliant by Design:** No personal data is ever collected or processed remotely.

---

## 🛠 Tech Stack

- **Frontend:** Pure HTML5, Modern CSS3 (Dark Mode / Glassmorphism), Native Vanilla JavaScript (ES6+).
- **Hosting:** GitHub Pages (Static hosting).
- **Dependencies:** None. Completely zero external SDKs or third-party tracking scripts.
